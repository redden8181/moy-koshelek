# Мой кошелёк 🌿

PWA для личных финансов: баланс, доходы и расходы, история с редактированием и удалением, свои категории с эмодзи, долги с частичным возвратом, планы и ежемесячные платежи.

## Приложение

https://redden8181.github.io/moy-koshelek/

На iPhone: Safari → Поделиться → На экран Домой. После первого полного открытия доступна работа без интернета. Напоминания показываются в приложении, без системных push-уведомлений.

При первом открытии — пять тестовых операций, баланс 6 637 ₽. Данные хранятся в браузере устройства и не отправляются на сервер. Синхронизации между устройствами нет. Экспорт и импорт JSON — в настройках. При переходе с прежнего адреса перенесите записи через экспорт на старом сайте и импорт на новом. Очистка данных браузера может удалить записи.

Ежемесячное напоминание появляется за 10 дней до даты. После оплаты исчезает до следующего срока; график остаётся в разделе планов. Повторная оплата будущего периода заблокирована. Все планы учитываются в запланированной сумме.

## Разработка и публикация

Статическое приложение HTML/CSS/JavaScript без зависимостей и сборки, файлы в `dist/`. Расчёты — целыми копейками.

```sh
npm test
python -m http.server 8080 --directory dist
```

GitHub Actions `.github/workflows/pages.yml` проверяет синтаксис и расчёты, затем публикует `dist/` при push в main или ручном запуске. Settings → Pages → Source: GitHub Actions.
