# Мой кошелёк 🌿

PWA для личных финансов: баланс, доходы и расходы, история с редактированием и удалением, свои категории с эмодзи, долги с частичным возвратом, планы и ежемесячные платежи.

## Приложение

https://redden8181.github.io/moy-koshelek/

На iPhone: Safari → Поделиться → На экран Домой. После первого полного открытия доступна работа без интернета. Напоминания показываются в приложении, без системных push-уведомлений.

При первом открытии — пять тестовых операций, баланс 6 637 ₽. Данные хранятся в браузере устройства и не отправляются на сервер. Синхронизации между устройствами нет. Экспорт и импорт JSON — в настройках. При переходе с прежнего адреса перенесите записи через экспорт на старом сайте и импорт на новом. Очистка данных браузера может удалить записи.

Ежемесячное напоминание появляется за 10 дней до даты. После оплаты исчезает до следующего срока; график остаётся в разделе планов. Повторная оплата будущего периода заблокирована. Все планы учитываются в запланированной сумме.

## Разработка и публикация

Статическое приложение HTML/CSS/JavaScript без зависимостей и сборки, файлы в `dist/`. Расчёты — целыми копейками.

```sh
npm test
python -m http.server 8080 --directory dist
```

GitHub Actions `.github/workflows/pages.yml` проверяет синтаксис и расчёты, затем публикует `dist/` при push в main или ручном запуске. Settings → Pages → Source: GitHub Actions.

## Месячные отчёты

На главной доходы, расходы и список операций относятся к текущему календарному месяцу. Общий баланс остаётся сквозным. «Отчёты» заменяют вкладку истории: каждый месяц содержит начальный остаток, доходы, расходы, поступления/выдачи по долгам и конечный остаток. Пустые месяцы между первым и текущим тоже отображаются.

Перенос остатка — расчётная строка, а не новая доходная операция. Исправление или удаление старой записи автоматически пересчитывает последующие остатки. Поиск по всем отчётам проверяет категории, комментарии, даты и имена людей по долгам; работают фильтры доходов, расходов и долгов.

Строки расходов выделены мягким красным, доходов — зелёным, долгов — нейтральным. Тип подписан текстом, поэтому различимость не зависит только от цвета. Новая стеклянная иконка подключена к manifest и apple-touch-icon. iOS может сохранить прежнюю иконку установленного ярлыка: при необходимости удалите только ярлык с главного экрана и добавьте сайт через Safari снова, не очищая данные сайта.

Проверено: 14 тестов расчётов и браузерные сценарии на ширине 320/390/1440px, перенос существующих данных v1 без сброса, поиск по разным месяцам, изменение старой операции и офлайн-перезапуск.

## Карточки долгов

Карточка показывает первоначальную сумму сделки даже после полного погашения, дату, направление («Я дал/взял в долг»), комментарий, возвращённую сумму и остаток. Для закрытых долгов дополнительно видна дата погашения. Нажатие на всю карточку открывает меню: операции, погашение, редактирование, удаление. Кнопка «История долга» убрана.

Редактирование долга меняет имя, исходную сумму, направление, дату и комментарий, сохраняя связанные возвраты. Сумма не может стать меньше уже возвращённой. Если у одного долга несколько исходных выдач, изменение общей суммы корректирует первую; для уменьшения ниже суммы остальных выдач редактируйте отдельные операции. Удаление с подтверждением удаляет весь долг вместе с его операциями и пересчитывает баланс и отчёты. Названия долговых операций берутся из фактического типа, поэтому старые названия категорий не путают выдачи с возвратами.
